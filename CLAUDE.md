# PowPow — Educational AI Gateway

PowPow is a multi-channel AI gateway built for educational purposes.
It is a fork of the openclaw project, enhanced and rebranded by Kannan.

## Purpose

This project is used to learn, experiment with, and enhance AI gateway capabilities
across multiple messaging channels (Telegram, Discord, Slack, WhatsApp, etc.)

## Getting Started

1. Copy `.env.example` to `.env` and fill in your API keys
2. Run `node powpow.mjs`

## Key Concepts

- **Gateway**: Central server that connects AI models to messaging channels
- **Skills**: Predefined AI behaviors in the `skills/` folder
- **Plugins**: Extensions in the `extensions/` folder
- **Channels**: Messaging platform integrations in `src/channels/`
