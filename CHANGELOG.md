# PowPow Changelog

All notable changes to PowPow will be documented here.

## [1.0.0] - 2026-02-26

### Added
- Initial fork from openclaw, rebranded as PowPow
- Educational enhancements and customizations by Kannan
- Support for all major AI providers: OpenAI, Anthropic, Gemini, OpenRouter, Bedrock
- Multi-channel messaging: Telegram, Discord, Slack, WhatsApp, LINE, Lark, and more
- Plugin and skills architecture
- Web UI (Lit Web Components)
